# Addendum 4: replicate the long-horizon recursion test on a second model (committed before any of its runs)

Written 2026-10-27 after the Addendum 3 result on Qwen2.5-Coder-1.5B, where `fixed` - `nonrec` at 8 rounds was
+2.83 [+1.17, +4.50] and gate gains in rounds 5-8 were 8 vs 2. A single model is not enough for a framework
claim, so the same test is repeated on Qwen2.5-Coder-7B-Instruct.

## Design

Identical to Addendum 3 except for the model:

* frozen seed program, MBPP gate/audit, the three test suites;
* `engine.rounds` = 8;
* arms `fixed` and `nonrec`, seeds 1-3;
* Baidu AIHC, one card per run.

Initial-model scores are paired within each run.

## Readings (decided now; the same rule as Addendum 3)

* **Recursion replicated:** `fixed` - `nonrec` at the final version is >= +1.0 point on CRUXEval-O, with the
  paired CI of the seed-averaged per-problem difference excluding 0, AND `nonrec` accepts fewer strict gate gains
  in rounds 5-8 than `fixed`, summed over seeds.
* **Otherwise:** "not replicated on the 7B model", reported as such next to the 1.5B result.
* **Secondary suites:** the 7B's fixed-program gains at 4 rounds sat mostly on LiveCodeBench-exec and
  CRUXEval-I. So the same comparison is also reported on those two suites, as secondary readings that do not
  change the verdict above.
* The result stays exploratory. Like Addendum 3, it was planned after a 4-round C3 result was seen.
