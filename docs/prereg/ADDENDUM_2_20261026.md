# Addendum 2: extra controls from the evidence survey (committed before any of their results)

Survey (2026-10-26) of how accepted self-improvement work proved itself (STOP, ADAS, DGM, HGM,
HyperAgents, SEAL, TTT-Discover, ThetaEvolve, Spurious Rewards, Mind the Gap). Additions, in priority:

1. **C5 iteration matters (compute-matched single round).** Arm `onebig`: one round from the initial model
   with the whole 4-round budget at once (proposals 24000, max cases 12000, curation budget 4000 cases,
   256 optimizer steps; same seed program otherwise). Bar: `fixed` (4 rounds) - `onebig` >= +1.0 point on
   CRUXEval-O with a paired CI excluding 0, seed-averaged over 3 seeds. Qwen2.5-Coder-1.5B, seeds 1-3.
   (Edit-space upper bounds were raised to admit this budget; nothing else changed.)
2. **Frozen-program transfer (planned).** Freeze the improvement program retained by `full` runs and run it
   as a fixed program from the initial model on Qwen2.5-Coder-7B and Granite-3.3-8B, against the seed
   program at equal rounds. Evidence for C4 that does not depend on the run that evolved it.
3. **Stronger-teacher data (planned).** Same counts and the same oracle filtering, but a larger model
   (CWM-32B or Qwen2.5-32B) proposes and solves the tasks that train the 1.5B model. Reported whichever way
   it comes out.
4. **C2 on non-Qwen models.** The shuffled-feedback control is also run on Granite-3.3-8B (random rewards
   are known to help Qwen through contamination and not other families).
5. Diagnostics reported for every run: gate-vs-audit gap of each accepted node, task diversity / novelty,
   and pass@k at k up to 64 on the final versions.
