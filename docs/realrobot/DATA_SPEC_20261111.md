# Real-robot demonstrations, batch of 2026-11-11 (colleague's teleoperation data)

Three scenes, 50 demonstrations each (150 in total), LeRobot v3.0, 30 fps. Four cameras at 960x540 h264: head stereo
`left_eye` / `right_eye` and `left_wrist` / `right_wrist`. Only the right arm does the task. The data is not in this
repository; it sits on the workstation at `/home/zeyu/realrobot_data/x_1111b/data-1111/<scene>/`.

| scene | task text | episodes | median length |
|---|---|---|---|
| apple2box | Put the apple into the white storage box. | 50 | 8.2 s |
| lemon2box | Put the lemon into the white storage box. | 50 | 7.7 s |
| open-the-drawer | Open the drawer. | 50 | 11.6 s |

## The 30-dimensional `observation.state` and `action` (layout stated by the colleague, 2026-11-11)

| dims | meaning |
|---|---|
| 0-6 | left arm joints (7) |
| 7-13 | right arm joints (7) |
| 14-20 | left end effector: x, y, z, quaternion (x, y, z, w) |
| 21-27 | right end effector: x, y, z, quaternion (x, y, z, w) |
| 28 | left gripper |
| 29 | right gripper |

Checked against the data:
- Every end-effector quaternion has unit norm, in both state and action.
- The action is the commanded target. It leads the measured state by 4 frames, about 130 ms, in every scene.
- The right gripper reads about 0 while the arm approaches. It rises to about 0.5-0.8 while an object or the handle is held, and returns to about 0 at release. So about 0 is open and larger means more closed. This is inferred and still to be confirmed.
- The left gripper never moves. The left arm drifts by a median of 6-7 cm per episode.
