## Style used by the current figures (keep it if you redraw)

- Sizes: one column 3.3 in wide, full width 7.0 in; font Liberation Sans / Arial, 7-7.5 pt; no figure titles inside the plot beyond panel titles.
- One colour per arm, the same in every figure, always with a text label as well:
  `fixed` (gated loop) #2a78d6, `full` (numeric meta) #eb6834, `llm_harness` (LLM meta) #1baf7a, `onebig` (one-shot RL) #008300, `nonrec` #6250d6, `shuffled` #e34948; reference levels in grey dashed #8a8983.
- Light grid, no top/right spines, white rings around markers that cross lines.
