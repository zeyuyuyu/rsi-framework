\section{A second domain: code world models}
\label{sec:code}

The same engine, with the sandboxed interpreter as oracle, trains a model to predict program outputs. Programs are written by the model itself (3-shot from a pool that starts with 16 hand-written seeds and grows with admitted programs; a program is admitted only if it is deterministic, literal-valued and not a near-duplicate of any held-out problem), attempted eight times with chain-of-thought, verified by execution, curated to at most two verified traces per case, and used for a LoRA SFT update; the gate is a 400-program validation set proposed by the \emph{initial} model. Held-out tests: CRUXEval-O (primary), CRUXEval-I and LiveCodeBench-execution, read only after retention is frozen. An independent re-scorer agrees with the engine on 99.6--100\% of test records.

\Cref{tab:code} summarises the registered comparisons. The verified loop improves every model on at least one test (CRUXEval-O $+2.6$ for the 1.5B model, LCB-execution $+5.8$ for the 7B model, both with CIs excluding 0), the permuted-label control does not, and the difference between them is significant on the trained task family ($+2.7$ $[0.9, 4.5]$). The numeric meta level does not beat the fixed program in any three-seed cell (the one two-seed exception, Qwen3-8B on CRUXEval-I, is not counted as a claim). Recursion is not detectable at four rounds ($-0.6$) but becomes significant at eight ($+2.8$ $[1.2, 4.5]$, replicated on the 7B model at $+2.9$ $[0.9, 4.8]$ and $+4.5$ $[1.6, 7.4]$ on LCB-execution): the frozen initial generator's practice is as good as the improving model's for about four rounds, after which the non-recursive arm stops accepting gate gains (2 vs 8 accepted gains in rounds 5--8) while the recursive arm keeps finding cases at its new frontier. The extra gain is on the trained task family with no extra forgetting on the secondary suites. This is the shape predicted for iterated on-policy learning~\cite{kim2026coverage}, and it suggests that the VLA recursion result of \cref{sec:libero} ($+1.7$ at six rounds) is on the same curve before it separates.
