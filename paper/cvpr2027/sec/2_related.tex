\section{Related work}
\label{sec:related}

\paragraph{Self-improvement with verifiers.} STaR~\cite{zelikman2022star}, ReST~\cite{gulcehre2023rest} and ReST-EM~\cite{singh2024restem} fine-tune a language model on its own verified rationales; SPIN~\cite{chen2024spin} and self-rewarding models~\cite{yuan2024selfrewarding} close the loop with the model as its own judge; Absolute Zero~\cite{zhao2025absolutezero} lets the model write its own tasks and uses a code executor as the verifier. RLVR with group-relative policy optimisation~\cite{shao2024deepseekmath,guo2025deepseekr1} is the dominant update rule. These works report that the loop helps; we ask which part of it helps. The iterated on-policy analysis of \cite{kim2026coverage} predicts the early saturation of a learner restricted to samples from the initial policy, which our non-recursive control shows at twelve rounds.

\paragraph{Meta levels that edit the procedure.} LLM-driven search over programs and training recipes has produced strong results when the search space is large and evaluation is cheap~\cite{novikov2025alphaevolve,lu2024aiscientist,hu2024adas}. Recent outer-loop systems put the weight on the harness around the proposer: Meta-Harness~\cite{lee2026metaharness} hands it every earlier candidate's code, scores and traces as files, EvoTrainer~\cite{chen2026evotrainer} adds layered diagnostics and a memory of failed branches, and LLMZero~\cite{fang2026llmzero} diagnoses training signals at checkpoints. Our last meta level follows them (\cref{sec:meta}). In our setting evaluation is expensive and noisy and the space is a few dozen knobs; there, a meta level that diagnoses correctly still cannot beat a fixed recipe that works, and we isolate the case where it can.

\paragraph{Robot self-improvement through code.} Concurrent systems let coding agents write and repair robot code from execution feedback: a code library with no model at run time~\cite{hu2026coap}, a validated skill hierarchy~\cite{wen2026roborsi}, or programs compiled from exploration~\cite{huang2026rax}. They improve code; we improve a VLA policy's weights and the program that trains them, and measure which ingredient of the loop is responsible.

\paragraph{RL for VLA policies.} OpenVLA~\cite{kim2024openvla} and OpenVLA-OFT~\cite{kim2025oft} are the policies we improve; SimpleVLA-RL~\cite{li2025simplevlarl}, RL4VLA~\cite{liu2025rl4vla} and related work~\cite{lu2025vlarl} apply on-policy RL to such policies in simulation with a binary success reward. We use the SimpleVLA-RL training stack as one update operator and its released checkpoints as starting points.

\paragraph{Preregistration.} Preregistered designs are standard in the experimental sciences~\cite{nosek2018preregistration} and have been proposed for machine learning~\cite{albanie2021preregistration}; we follow the practice literally, with every change a dated public amendment.
